블루링크 주행거리 연결

STEP 1

현대 계정 로그인

콘솔 → 설정의 Client ID를 넣으세요. (Client Secret은 여기 넣지 않습니다)

STEP 2

GitHub에서 실행

바로 GitHub 저장소 → Actions → 현대 주행거리 자동 갱신 → Run workflow → 칸에 붙여넣고 실행하세요. 인증 코드는 몇 분 안에 만료됩니다.
실행이 끝나면 이 브라우저에서 이 페이지를 다시 열어 두세요. 자동으로 STEP 3이 열립니다.

STEP 3

차량 데이터 제공 동의

GitHub 실행 결과를 기다리는 중… (실행 후 반영까지 1~2분)
